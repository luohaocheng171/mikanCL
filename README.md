## 写在前面

MikanCL 是一个面向 Windows 10 / 11 的 Minecraft 启动器。它想做的事情很朴素：把「装游戏、装 Mod、装整合包、找资源、开联机、修存档」这些零碎活儿，收进同一个窗口里，让你少开几个网页、少翻几篇教程。

它不要求你先学会一堆术语。Java 不对会告诉你该装哪个；Mod 缺前置会标出来；整合包装到一半失败会留下清单；游戏启动卡住了会问你要不要强制结束。能自动判断的就自动判断，判断不了的就用中文说清楚。

界面默认推荐美化版（Edge WebView2 渲染，毛玻璃、悬浮卡片、动画）；经典版（Qt 自绘，轻、稳、占用低）适合老机器。另外提供 **Electron 独立版**：自带 Chromium，不依赖 WebView2，渲染的是同一套网页前端。第一次启动会让你三选一，之后随时能在「设置 → 外观 → 界面框架」里换；从 v5.3.1 起独立版已内置进 `MikanCL.exe`，第一次切换会自动释放到 `data/electron/app/`，之后直接复用。三套界面共用同一份账号、实例、下载任务和配置，不用重新装游戏。

这份说明按「先上手 → 页面导览 → 细节与小道具 → 排错 → 开发」的顺序写。第一次用，看前两节就够；想挖功能，可以直接跳到「页面导览」。

## 一分钟上手

1. **下载并打开**：拿到 `MikanCL.exe` 后双击即可，不需要安装 Python，也不需要解压一堆文件。配置、账号、缓存都会写在 exe 旁边的 `data/` 目录里，换电脑时整个文件夹拷走就能接着用。

2. **选择界面**：第一次启动会弹一个小窗口，三个选项：默认推荐「美化版」，视觉更完整；老机器、小内存或不想装 WebView2 选「经典版」；「独立版（Electron）」自带 Chromium、完全脱离依赖，但安装包和内存占用更高。选错了也没关系，设置 → 外观里随时能换。

3. **同意协议**：第一次启动需要阅读并同意用户协议（当前 v1.9，共 15 项）。协议会用 5 种语言随界面切换，点「不同意」会直接退出，不会偷偷进主界面。

4. **先准备 Java**：打开「下载中心 → Java」（经典版是左侧「Java 中心」），选一个发行版和主版本（不知道怎么选就用默认推荐），点安装。也可以让启动器在启动前自动检测；检测不到时会带你去 Java 中心。

5. **装一个游戏版本**：打开「下载中心 → 游戏版本」（经典版是左侧「下载」页），选一个正式版，点安装。想装 Forge / Fabric / NeoForge / Quilt / LiteLoader，可以在同一个安装面板里直接选加载器，不用装完原版再跑一趟。

6. **回主页启动**：在主页选中刚装好的版本，点「启动游戏」。第一次启动会做几项检查，通过后就开始下载/校验文件并拉起游戏。

7. **想登录就登录**：微软正版走设备码登录；有皮肤站账号可以走 authlib 外置登录；什么都不想登就用离线账号。登录不是启动游戏的硬性前提。

小提示：不装游戏也能先用内容中心、教程中心、世界种子、皮肤工厂这些不需要启动游戏的功能。

## MikanCL 能做什么

| 你想做的事 | MikanCL 里的做法 |
| :--- | :--- |
| 装一个原版游戏 | 「下载中心 → 游戏版本」选版本，自动下载客户端、依赖库、natives 与资源文件，回主页双击启动 |
| 装基岩版 | 「下载中心 → 基岩版」按历史版本 / 微软商店正式版 / 预览版浏览，用内置 Edge 内核打开下载页，Appx 下载完自动归档，再一键安装、启动或卸载 |
| 装 Forge / Fabric / NeoForge / Quilt / LiteLoader | 在同一个安装面板里选加载器版本，一键装完；会自动匹配需要的 Java 主版本 |
| 装整合包 | 把压缩包拖进窗口，或从「整合包」页导入；自动装基础版本、装加载器、刷入 overrides、注册独立实例 |
| 找 Mod、整合包、资源包、光影包、材质包 | 「内容中心」双平台搜索，可按 MC 版本、加载器、来源、用途、材质分辨率过滤，一键装进实例或另存为 |
| 用中文找 Mod | 直接搜「机械动力」「物品管理器」这类中文词，卡片会自动补上中文译名 |
| 和朋友联机 | 「联机」页用陶瓦（Terracotta）房间码组网，不需要端口映射或公网 IP |
| 换 Java / 装 Java | 「Java 中心」提供 12 家发行版，可选轻量 JRE 或完整 JDK；支持 ZIP 便携版与官方安装程序，ZIP 版会自动解压并写入用户 PATH |
| 检查缺文件、缺 Java | 「依赖补全」按联机 / 登录 / 运行环境 / 加载器分类列出第三方依赖，缺什么补什么；版本体检会检查 Java、客户端 Jar、依赖库、资源与日志配置 |
| 管账号与皮肤 | 微软正版设备码登录、皮肤站外置登录、离线账号；皮肤查询 / 上传 / 本地导入 / 快速切换 / 自己的皮肤库 |
| 从 PCL / HMCL 换过来 | 「工具箱 → 导入 HMCL / PCL」扫描对方目录，把本启动器没有的版本登记进来，并尽量沿用内存、Java、JVM 参数；Mod 与存档仍留在原目录 |
| 排查「装上了但起不来」 | 启动前五项预检 + Mod 冲突检测 + 崩溃弹窗一键修复 + 启动卡死看门狗 + 日志落盘 |
| 不会装、装崩了想查教程 | 「教程中心」内置 Markdown 攻略，支持标题与正文搜索；也可以自己新建教程 |
| 改世界种子 / 游戏模式 | 「NBT 编辑器」可视化读写 `level.dat` 与 `playerdata/*.dat`；「存档编辑」可以改世界名、模式、难度、天气、时间、出生点与常用规则 |
| 多个版本互不干扰 | 4 种隔离模式（不隔离 / 仅 Mod / 仅存档 / 全部隔离），整合包自动独立目录；主页可切换本机任意版本文件夹 |
| 下载进度随手看 | 有任务时窗口右下角会出现任务胶囊（经典版是圆形悬浮球），点一下回到下载中心 |
| 小屏幕 / 想调窗口 | 无边框窗口可拖四边四角缩放，内容放不下就出滚动条，不会把卡片压扁 |
| 自己画皮肤 | 「皮肤工厂」像素级编辑 64×64 皮肤，10 种工具、镜像、撤销重做、最多 8 层、3D 模型直接作画 |
| 挑种子不想进游戏 | 「世界种子」调用本机 Java 运行内嵌地形生成器，经典版带 3D 体素预览，美化版生成高度图 |
| 想要更炫的界面又怕卡 | 经典 / 美化两套框架随时切换；美化版还能单独关闭毛玻璃与动画 |
| 只想安安静静看截图 | 「截图图库」按实例读取 `screenshots/`，点击预览，可批量打包 zip、打开或删除，不联网、不上传 |
| 游戏崩了想找原因 | 「崩溃报告」汇总归档日志，支持预览、复制摘要、打开目录与删除 |
| 下载时想知道还差多少 | 经典版安装进度会按「实际需要下载的文件」累计，显示「剩余 N / 共 M 个文件」；三套界面都能看到进度与速度 |
| 关软件不想等 | 美化版点关闭会先落盘再快速退出；经典版如果还有下载任务，会先问「关闭（中断下载）」还是「手滑了」 |
| 导航太多看不过来 | 侧边栏按「启动 / 下载 / 内容 / 联机 / 工具 / 设置」分组；关掉的功能模块会整组隐藏 |
| 想按自己的习惯排版本 | 版本列表支持拖动排序，松手后写回配置；美化版版本多时会出现搜索框 |
| 想直观看出谁缺前置、谁在循环依赖 | 「Mod 关系网」把 `mods/` 的前置关系画成可缩放平移的网：红色 = 缺前置，橙色 = 循环依赖，虚线 = 缺失依赖 |
| 想让游戏更流畅又不想乱改参数 | 「智能 JVM 参数」按 Java / 游戏版本自动挑 GC 与内存参数，设置里还能单独开关堆预触碰、固定堆大小 |
| 想把 2009 年的老存档搬进新版本 | 「工具箱 → 存档转换」把 Classic / Indev / Alpha / McRegion 逐级转成 Anvil，再输出到目标版本的 saves 目录 |
| 想让游戏里也是毛玻璃 UI | 「UI 材质包一键替换」为选中版本生成半透明界面材质包，按版本自动适配并写入 |
| 配置改坏了想退回去 | 「设置 → 高级 → 恢复到上次能启动的配置」把内存 / JVM / 参数恢复到上一次成功启动时的状态，不动 Mod 与存档 |
| 想快速找到某个功能 | 美化版按 `Ctrl+K` 打开命令面板，输入「种子」「Java」「皮肤」就能直接跳转 |

## 三套界面，同一份数据

| | 经典版 | 美化版（默认推荐） | Electron 独立版 |
| :--- | :--- | :--- | :--- |
| 渲染方式 | PySide6 / Qt6 自绘 | pywebview + Edge WebView2（Chromium） | Electron 自带 Chromium |
| 视觉风格 | 深色、紧凑、稳定 | 毛玻璃、圆角、悬浮卡片、渐变按钮 | 与美化版共用同一套 HTML / CSS / JS |
| 导航 | 默认 23 个入口，按板块分组 | 11 个页面，下载页再分 6 个标签 | 11 个页面，与美化版完全一致 |
| 默认窗口 | 1080×680，最小 900×540 | 1120×720，最小 960×600 | 1120×720，最小 960×600 |
| 额外依赖 | 无 | WebView2 Runtime（Windows 10 / 11 通常已带） | 无（自带 Chromium，不依赖 WebView2） |
| 适合 | 老机器、小内存、习惯传统布局 | 喜欢视觉、屏幕较大、想自己调外观 | 受管电脑、无法安装 WebView2、想要完全独立的内核 |

三套界面不是三个启动器：

- 账号、实例、版本、下载任务、配置、皮肤库都存在同一份 `data/` 里，切框架不用重新登录或重装。
- 美化版把常用功能拆成主页、下载中心、内容中心、实例管理、版本设置、账号与皮肤、联机、教程中心、浏览器、工具箱、设置 11 个页面。
- 美化版的下载页有 6 个标签：游戏版本、加载器、Java、基岩版、下载加速、任务。
- 美化版的设置页有 6 个标签：常规、外观、下载、高级、扩展、关于。
- 如果系统缺少 WebView2，会弹窗引导下载；下载失败或渲染失败时可以直接切回经典版，不会卡在打不开的界面。
- Electron 独立版不重写界面：它直接加载 `mc_launcher/ui_web/web` 下的同一套网页，只把 `window.pywebview.api` 桥接到内置的 Python 后端；窗口、文件对话框、内置浏览器由 Electron 原生实现。
- 三套界面的呈现方式略有不同，文中会注明「经典版」「美化版」或「Electron 版」；没有注明的功能三套都有。

### Electron 独立版怎么来

从 v5.3.1 起，独立版**直接并进 `MikanCL.exe` 这一个文件**，不再要求用户另外找安装包：

```powershell
python build_electron.py --all    # 后端 + Electron 解包版 + 单文件内置包（需要 Node.js / npm）
python build_exe.py               # 把内置包一起打进 dist/MikanCL.exe
```

- `build_electron.py --all` 会生成 `electron_bundle/MikanCL-Electron.zip`，`build_exe.py` 检测到这个文件就会一起打包，并在输出里提示附带体积。
- 第一次切到独立版时，启动器把内置包释放到 `data/electron/app/`，之后每次直接运行缓存里的 `MikanCL.exe`，不会重复解压。
- 内置包只保留运行所需的组件：排除 QtWebEngine、QtQuick、QtMultimedia 以及 pywebview / pythonnet，Chromium 由 Electron 自带。
- 仍然共用同一份 `data/`：账号、实例、存档、配置在三种界面之间直接可见，切换不需要重新登录。
- 也支持外部产物：把解包版放到 `electron/`、`electron/dist/win-unpacked/`，或把便携版放到 exe 同级目录，启动器会优先使用它们，方便调试和热更新。
- 单文件因此会比 v5.2.0 大（多出约 160 MB 的内置包），首次启动解压时间也会略长；这是“一个 exe 带三种界面”的代价，换来的是不用再单独分发 Electron 产物。

## 页面导览

### 主页：今天玩哪个版本

主页是启动器最常待的地方，信息尽量摊开，但不堆在一起。

- **版本列表**：每个已安装版本一张卡片，卡片上能看到版本类型和加载器。点一下选中，双击直接启动。
- **搜索与排序**：版本多了可以搜索；按住卡片上下拖动可以换顺序，松手后自动写回配置，下次打开还是这个顺序。
- **实例与数据目录**：美化版主页顶部有实例下拉和版本下拉；本机有多个数据目录时，还会多一个目录下拉，切过去就刷新版本列表。
- **最近皮肤**：主页右侧会显示最近用过的皮肤，点一下就能换，不用进账号页。
- **多选启动**：勾选多个版本，按顺序启动；上一个游戏退出后自动启动下一个，失败会跳过并继续，队列进行中也可以停止。经典版在主页，美化版在实例管理页。
- **拖拽导入**：把 Mod、整个 `mods` 文件夹、整合包、资源包、光影包或世界 zip 拖进窗口，启动器会先问你要装到哪个实例。
- **空状态引导**：没有版本时不会只写「暂无」，而是告诉你下一步该去下载版本还是导入整合包。
- **启动动画**：经典版点启动后，主页会覆盖一层 256×256 的草方块进度，按真实下载进度逐格填满，下面显示阶段文字和百分比，还会随机挑一句启动词。美化版用任务胶囊和状态栏显示进度。动画可以在设置里关掉。
- **启动后行为**：可以设置启动游戏后保持窗口、隐藏启动器或关闭启动器；经典版还支持关闭到托盘。
- **最近使用**：美化版主页会记住最近打开的功能，最多 5 个，下次一点就到。

### 下载中心：原版、加载器、Java、基岩版都在这

经典版把「下载安装」和「下载中心」分成了两个页面；美化版把它们收进「下载中心」的 6 个标签里。

- **游戏版本**：可按正式版、快照、旧版本、愚人节版筛选。点「安装」可以选纯原版，也可以在同一个面板里直接挑 Forge / Fabric / NeoForge / Quilt / LiteLoader / Forbric，一次装完。
- **磁盘预估**：经典版在安装前会按版本清单估算客户端、依赖库和资源文件的总大小；空间不够会提前提示「约需 X GB，当前剩 Y GB」，而不是下到一半才失败。
- **只下载不安装**：原版客户端 Jar 可以单独另存；加载器安装器也可以只保存到指定目录，方便归档、离线部署或交给别的启动器。
- **加载器**：5 款主流加载器加 1 款实验性的 Forbric。选好 MC 版本后会拉取对应加载器版本，安装日志实时滚动；Forbric 只支持 26.2，会在界面上明确提示。
- **Java**：12 家发行版、JRE / JDK 可选、ZIP 或官方安装程序、自动写入 PATH，详见下面的「Java 中心」。
- **基岩版**：历史版本、商店正式版、预览版三个来源，详见下面的「基岩版」。
- **下载加速**：粘贴任意直链或一段包含链接的文本，启动器会提取链接，用同一套多线程下载器下载；线程数可调，支持断点续传和自定义保存目录。
- **任务**：所有下载和安装都在任务列表里，支持暂停、继续、取消、重试、删除任务、打开目录；右上角「打开下载文件夹」直接跳到手动下载的位置；删除任务不会删掉已经下载好的文件。

### 内容中心：中文也能搜 Mod

内容中心接的是 Modrinth 和 CurseForge，两边的搜索、筛选和安装流程尽量做成一样的。

- **五种类型**：Mod、整合包、资源包、材质包、光影包分开搜索，不再把「资源包」和「材质包」混在一起。
- **筛选**：来源、MC 版本、加载器、用途分类可以组合；材质包还能按 8x- / 16x / 32x / 48x / 64x / 128x / 256x / 512x+ 分辨率筛。
- **中文译名**：卡片的英文标题会在后台逐张补中文名，比如 `Sodium → 钠`、`Iris → 虹膜光影`。译名来自本地词表和 MC百科搜索结果的「中文名 (English Name)」配对，带节流、磁盘缓存和失败负缓存，不会卡住搜索结果。
- **中文搜索**：直接输入中文；本地词表没命中时，会把中文反查成英文项目名再交给平台搜索。
- **用途分类**：优化、辅助、前置、装饰、科技、魔法、冒险、农业、世界生成等按钮，点一下按用途过滤。
- **详情页先选版本**：点进项目不会一下铺开所有文件，而是先按支持的 Minecraft 版本分组；选了版本才列出可用的 Jar，并按稳定版 / 测试版分组，标注加载器、日期和大小。
- **前置依赖提示**：进入文件列表后会自动解析必需前置，缺哪个、要不要额外装，都会在卡片上标出来；安装时仍会自动补齐必需前置。
- **安装或另存**：可以一键装进当前实例，也可以只下载到指定目录。Mod 会进 `mods/`，资源包进 `resourcepacks/`，光影包进 `shaderpacks/`，材质包按资源包处理。

### 整合包：拖进来，剩下交给它

整合包安装是启动器里最容易被低估的部分，MikanCL 把它拆得比较细。

- **三种导入方式**：拖进窗口、从「整合包」页选文件、在版本设置里「导入到当前实例」。
- **安装流水线**：识别清单 → 装基础游戏版本 → 装指定加载器 → 刷入 `overrides` / `client-overrides` → 注册独立实例。每一步都有日志和进度。
- **直装包兜底**：没有清单、但里面有 `mods/` 或 `config/` 的压缩包，会按直装包处理，并尽量推断 MC 版本。
- **失败不中断**：某个 Mod 下载失败不会让整个整合包报废，失败项会写进 `missing_mods.txt`，装完再补。
- **双格式**：CurseForge 分享格式（`manifest.json` + `overrides`）和私有 `.mikan` 格式都能导入导出。
- **装进现有实例**：不想新建实例时，可以选择「附加到已有版本」；清单里的在线 Mod 不会自动下载，装完后到模组管理里补齐。
- **嵌套目录**：压缩包外面多套一层文件夹也能识别，不会因为路径多一层就找不到清单。

### 实例管理：一个版本一间房

实例可以理解成「一个版本 + 一个加载器 + 一套独立目录」。整合包导入后会自动变成一个实例，互不打扰。

- **新建与切换**：可以从版本新建实例，也可以直接选一个现成实例；主页和版本设置页都能切。
- **改名、排序、移除**：实例可以改名、上移下移；「移除」只删启动器里的记录，不会删磁盘上的游戏文件。
- **隔离模式**：不隔离、仅 Mod、仅存档、全部隔离。新版本默认「全部隔离」，每个版本用自己的 `versions/<id>/game` 目录。
- **修复实例**：一键校验并补全原版与加载器文件，修完自动更新实例的版本记录。
- **导出整合包**：可以把当前实例打包成 `.mikan` 私有备份，或带 `manifest.json` 的 CurseForge 整合包 zip，包含 mods、资源包、光影包、config 与 `options.txt`。
- **批量工具**：批量健康检查、批量补全文件、批量导出配置，适合一次整理很多版本。
- **数据目录**：可以添加多个 `.minecraft` 根目录、`versions` 目录或单个版本文件夹；启动器会识别层级并切换过去。

### 版本设置：七个标签，把细节都摊开

v5.2.0 把经典版的版本设置完整搬到了美化版，单独开了一个页面。顶部可以切换实例和版本，下面 7 个标签对应经典版的全部设置，底部还有一排快捷工具。

#### 概览

版本 ID、类型、加载器、Java、内存、游戏目录、版本目录、Mods 目录、Mod 数量等一眼能看到。常用按钮包括启动、打开游戏 / 版本 / Mods 目录、复制版本 ID、健康检查、修复版本和删除版本。删除版本不会删存档。

#### 游戏设置

全局的 Java、内存、窗口大小、JVM 参数、游戏参数、自动进服、启动后隐藏等选项在这里；单个版本还可以单独覆盖隔离模式、内存、进程优先级、窗口标题、额外 JVM 参数和额外游戏参数。不想单独设置就选「跟随全局」。

参数多的标签提供「常用 / 高级」双视图，默认只显示常用项，点一下「显示全部」再展开，避免一上来被几十个字段劝退。

#### 模组管理

列出当前版本的 Mod，支持启用 / 禁用（用 `.disabled` 后缀，和经典版约定一致）、删除、打开目录、从文件安装、在线添加、检查更新、一键更新可更新项。重复 modid、前置缺失、版本范围不满足会标红并给处理建议；缺前置可以直接点去安装。

#### 资源包管理

列出 `resourcepacks/` 里的资源包，支持启用 / 禁用、上移 / 下移、打开目录、在线添加、从文件导入。排序会写回 `options.txt` 的 `resourcePacks` 列表，下次进游戏顺序不变。

#### 光影包管理

列出 `shaderpacks/` 里的光影包，支持启用 / 禁用、删除、打开目录、在线添加和从文件导入。

#### 整合包

可以把当前实例导出为 `.mikan` 备份，也可以把整合包导入当前实例。导入会处理 `overrides` / `client-overrides`，覆盖前会确认；清单里的在线 Mod 需要装完后到模组管理补齐，不会偷偷下载一大堆东西。

#### 版本管理

改名、删除、修复版本、批量健康检查、批量补全、批量导出配置、清理游戏目录、导出启动脚本（`.bat` / `.ps1` / `.sh`，含完整命令行与工作目录）都在这里。清理会删启动器日志（保留最近 3 个）、`versions/*/natives`、`*.tmp` / `*.part` 与 7 天前的 `crash-reports`，不会动存档和 Mod。

这一页底部还有一排存档与快捷工具：

- **存档列表**：按实例读取 `saves/`，支持备份、恢复、导出 zip、导入世界、编辑、NBT、转换和删除。
- **存档编辑**：改世界名称、游戏模式、难度、是否允许作弊、天气、时间、出生点与常用游戏规则；写入前自动备份 `level.dat`，最多保留 5 份。
- **版本标记转换**：把 `level.dat` 的版本标记 / DataVersion 改写成目标版本。它只改标记，不做区块升级，适合同一种 Anvil 格式跨小版本；跨大版本请先整份备份。
- **完整存档转换**：跳到工具箱的存档转换器，处理 2009 年以来的旧格式，见下面的「数据、存档与皮肤」。
- **启动前自动备份**：默认开启，每个存档单独打包到备份目录；同一个世界 1 分钟内不会重复备份，最多保留 20 份。
- **快捷入口**：世界种子、截图图库、崩溃报告、Mod 关系网、依赖补全都能从这里一键跳过去。

### 账号与皮肤

- **三种账号**：微软正版设备码登录、authlib 外置登录（皮肤站）、离线账号。正版登录会显示设备码和倒计时，刷新令牌失败会提示重新登录。
- **皮肤**：可以按玩家名查询皮肤、上传皮肤、导入本地 PNG；导入时选 Steve / Alex 模型，也可以勾选「覆盖所有已安装版本」。
- **皮肤库**：导入过的皮肤会自动进 `data/skins/library/`，按 sha1 去重，最近使用优先，最多 60 条；侧栏头像点一下就能弹出最近皮肤。
- **头像就是皮肤头**：主页、侧栏、账号页不再用随机像素头像，而是从皮肤文件裁出「头部 + 帽子层」生成圆角头像；本地没有皮肤时会异步拉取皮肤站地址补全。
- **皮肤包**：可以按玩家名、版本、手臂模型、披风生成皮肤包 zip，也可以导入到指定版本、补齐缺失、一键覆盖所有已安装版本。服务端如果装了 CustomSkinLoader，别的玩家也能看到你的皮肤。
- **皮肤工厂**：64×64 像素画布，画笔、橡皮、填充、取色、加亮、加深、直线、矩形、椭圆、喷枪 10 种工具；支持镜像对称、撤销重做、2×–12× 缩放、网格开关、按部位高亮 UV；最多 8 层，可新建 / 删除 / 排序 / 显隐，导出时自动合并。右侧 3D 模型可以选中部位直接画，底层 / 第二层切换，左转 / 右转 / 复位、滑块旋转、自动旋转都有；经典版还能导入 64×32 披风并预览在模型背后。
- **UI 材质包**：为选中版本生成半透明毛玻璃界面材质包，可以只生成、导入到指定版本、导入全部已安装版本，也可以导出 zip 或直接启用。

### 联机：把房间码发给朋友

- **陶瓦联机**：第一次用会下载并校验官方发行包，房主创建房间，朋友输入房间码加入；结束后一键关闭联机进程。
- **房间码**：大号等宽字体显示，支持一键复制；创建后会自动轮询房间状态，加入前会先把房间码格式规范化。
- **地址探测**：生成联机地址后会自动试连并显示延迟，失败可以手动复测，不用等进游戏才发现连不上。
- **服务器列表**：可以添加、编辑、删除服务器，支持 Minecraft Server List Ping，显示 MOTD、在线人数、延迟和图标；可以设为主服务器，启动时自动进服。

### 基岩版：Java 版之外的另一个入口

- **三个来源**：MCAPPX 历史版本、微软商店正式版、预览版；可以按架构筛选、搜索，列表里能看到版本号、渠道和更新时间。
- **下载与归档**：点「在浏览器下载」会用内置 Edge 内核打开下载页；下载完成的 `.appx` / `.msix` 会自动归档到本地，不用自己翻下载文件夹。
- **安装与启动**：安装走 `Add-AppxPackage`，缺 VCLibs 时会先补依赖再重试；启动按 AUMID 拉起游戏，也可以一键卸载。
- **和主界面联动**：基岩版安装状态会显示在下载页，主页也有直达入口；不需要装 Java。
- **提醒**：基岩版需要微软账号拥有游戏或 Game Pass；提示 `0x803F8001` 通常是账号没登录、没购买或商店区域不对，不是启动器坏了。

### Java 中心：不用自己找 Java

- **12 家发行版**：Adoptium Temurin、Microsoft OpenJDK、Azul Zulu、Amazon Corretto、Alibaba Dragonwell、Tencent Kona、BellSoft Liberica、IBM Semeru、SAP SapMachine、GraalVM、清华 TUNA、华为云。国内网络可以优先选 TUNA 或华为云。
- **JRE / JDK**：只玩游戏选轻量 JRE，要开发或跑服务端选完整 JDK。
- **安装方式**：ZIP 便携版会自动解压到 Java 目录，并把 `bin` 写入用户 PATH；也可以选官方安装程序（EXE 或 MSI，按发行版提供），走系统向导安装。
- **下载**：大文件多线程分段下载，支持暂停、取消和断点续传，任务统一进下载中心。
- **检测**：会查 `JAVA_HOME`、注册表、常见安装目录、PATH、`where java`、Gradle 缓存等位置；也可以手动添加 Java 路径。
- **选择与推荐**：启动器会按游戏版本挑合适的 Java 主版本（常见 8 / 11 / 17 / 21），并根据物理内存推荐游戏内存，避免一上来就分太多。
- **预加载 JVM**：设置的高级里有一个实验性开关，启动器启动时会用所选 Java 预热一次 JVM，缩短反复启动的等待；默认关闭，低配机器开着反而更占内存。

### 教程中心：遇到问题先翻两页

- **内置教程**：中文 19 篇，英文 18 篇，俄文 / 法文 / 日文各 8 篇；首次运行会按界面语言写入 `data/wiki/<语言代码>/`。
- **可以自己改**：教程就是 Markdown 文件，直接改文件就能扩充；也可以在教程中心点「新建教程」，创建空 Markdown 并调用系统编辑器打开。
- **搜索**：支持按标题和正文搜索；站内锚点就地跳转，外链交给系统浏览器。
- **内容**：安装 Forge / Fabric、装光影、内存不足、Mod 冲突、Java 版本、NBT 编辑器、离线皮肤、存档备份等常见问题都有。

### 内置浏览器：在启动器里看 B 站

- **Edge 内核**：默认托管系统自带的 Edge WebView2，完整 Chromium，自带 H.264 / AAC，B 站视频可以直接播放、支持全屏。
- **登录态保留**：Cookie 与登录状态会留在本地（经典版在 `data/browser/webview2`，美化版在 `data/webview2`），一次登录长期有效。
- **多标签（经典版）**：支持新建标签、关闭标签、地址栏、前进后退、刷新、在系统浏览器打开；弹窗可以接管成新标签。美化版是独立的浏览器窗口，打开链接就能直接看。
- **回退（经典版）**：只有系统缺失 WebView2 时才回退到 QtWebEngine，并显示「视频可能无法播放」的提示条；美化版没有这层回退，缺 WebView2 时按启动器的引导安装即可。

### 工具箱：一堆顺手的小工具

- **依赖补全**：按联机 / 登录 / 运行环境 / 加载器分类列出陶瓦、authlib-injector、Java 运行时、加载器与 Forbric，显示已安装 / 缺失 / 按需安装；缺失项可以直接下载或跳到对应页面。
- **版本体检**：选一个版本，检查 Java、客户端 Jar、依赖库、资源文件与日志配置；确认后静默补全，任务进下载中心。
- **第三方组件**：集中管理不能随启动器内置的组件，说明为什么不能内置、装到哪里、怎么更新。
- **Mod 关系网**：把 `mods/` 的前置依赖画成可缩放平移的网；红色节点是缺前置，橙色边框 / 连线是循环依赖，虚线是缺失依赖。
- **存档管理**：列出所有实例的存档和备份，支持备份、恢复、导入世界、导出 zip、打开目录和删除。
- **存档转换**：完整转换器，支持 Classic / Indev / Alpha / McRegion → Anvil → 目标版本，多线程、可取消、有日志和方块 ID 重映射。
- **截图图库**：按实例读取截图，点击预览，批量打包 zip、打开或删除。
- **崩溃报告**：汇总归档日志，预览、复制摘要、打开目录、删除。
- **世界种子**：输入种子，调用本机 Java 运行内嵌地形生成器（与原版相同的 ImprovedNoise / 气候噪声参数），经典版用 WebGL 渲染 3D 体素地形，美化版生成高度图；尺寸可选，结果会保存到本地。
- **NBT 编辑器**：纯 Python 手写 NBT 读写，支持 13 种标签、自动识别 gzip、写回时保留原标签类型；树形查看 `level.dat` / `playerdata`，双击改叶子值、右键增删标签、根节点保护、未保存提醒，首次保存自动生成 `.bak`。
- **导入与清理**：导入整合包、导入 HMCL / PCL、清理缓存；清理只删损坏 / 未完成的版本与缓存，不会动存档和 Mods。

## 那些值得单独说说的小设计

下面这些不是「大功能」，但都是日常会用到的细节。下面几处标了「少见」：这些功能在 PCL2、HMCL、Prism Launcher、MultiMC 和官方启动器里不常见，但不保证全世界只有 MikanCL 有，所以不滥用「独家」这个词。

### 找内容更省劲

- **中文译名不是机翻**：优先查本地常用词表，缺词才联网；译名来自 MC百科搜索结果的「中文名 (English Name)」配对，带 1 秒节流、磁盘缓存和失败负缓存，不会因为一个词查不到就卡住整页。
- **中文搜索是双向的**：先查本地词表，没命中就把中文反查成英文项目名，再交给平台搜索；搜「物品管理器」也能找到 JEI。
- **材质包单独分类**：把「材质包」从「资源包」里拆出来，按 8x- 到 512x+ 的分辨率检索，安装时落到实例的 `resourcepacks/`。
- **用途分类不靠网络**：本地词表 + 平台标签 + 中英文关键词共同判定，点「优化」只出优化类，不会混进一堆装饰 Mod。
- **先选游戏版本，再列文件**：避免在一大堆不兼容的 Jar 里翻；选中版本后还会按稳定版 / 测试版分组。
- **前置依赖提前说**：文件列表里就把必需前置、缺失状态和跳转入口标出来，安装时仍会自动补齐。

### 下载和安装更稳

- **统一下载中心**：原版安装、加载器、整合包、内容文件、Java、基岩版、纯文件「另存为」都是同一类任务，统一进度、速度、暂停 / 恢复 / 取消 / 重试 / 打开目录。
- **断点续传 + 多源重试**：文件先写 `.part`，完成后改名；某个源失败会自动换源重试，不会整包重下。
- **只下载不安装**：加载器安装器、原版客户端 Jar 都能单独保存，方便归档或交给别的启动器。
- **一次装 5 个版本**：经典版支持最多 5 个版本同时安装，超出的排队；单个版本内部再按文件并发，不会把磁盘和网络一次性打满。
- **安装前先算空间（经典版）**：按清单估算客户端、依赖库与资源文件大小，空间不够提前说，而不是下到一半报错。
- **直装包兜底**：没有清单的压缩包，只要里面有 `mods/` 或 `config/` 就按直装包处理，并尽量推断 MC 版本。
- **失败清单**：整合包里某个 Mod 下载失败，会写进 `missing_mods.txt`，不中断整个安装。
- **双格式整合包**：CurseForge 分享格式和私有 `.mikan` 格式双向导入导出。
- **线程和限速**：下载线程数可调（最高 328），也可以限速、走代理；下载加速页支持粘贴任意直链。

### 启动和排错更直白

- **启动前五项预检**：Java 主版本不匹配（可确认强启）、内存超过物理内存 70%、Mod 冲突、磁盘剩余小于 2 GB、核显 + 光影组合，启动前直接说清楚问题出在哪。
- **Mod 冲突检测**：解析 `fabric.mod.json` / `META-INF/mods.toml` / `mcmod.info`，检测重复 modid、前置缺失、版本范围不满足，在表格里标红并给处理建议。
- **启动卡死看门狗【少见】**：启动后 30 秒内既没检测到游戏窗口、进程又还活着（或 CPU 时间一直是 0），会提示「游戏可能卡在初始化」，并给一个「强制结束并查看日志」按钮。这个做法在启动器里不常见，但不是唯一，所以标「少见」。
- **崩溃一键修复**：识别到 `UnsupportedClassVersionError` 时提供「去装所需 Java」（比如 1.20.5+ 需要 Java 21）；`libraries` / `assets` 缺失时提供「补全缺失文件」；版本 JSON 损坏时提供「修复版本」，备份坏 JSON 后从清单重拉，保留本地 jar 与库。
- **启动提示更直白**：启动完成后会说明本次自动启用了哪些参数（比如 G1GC、内存、跳过了哪些自定义 GC），不只写进日志。
- **恢复到上次能启动的配置**：把内存、JVM 参数等启动配置恢复到上一次成功启动时的状态，不动 Mod 与存档；也可以把当前配置导出成 `.mikan` 分享片段。
- **日志落盘**：界面日志、`install_error.log`、崩溃归档都留在 `data/logs/`，出问题时不用靠回忆。
- **单实例保护**：同时开两个启动器会提示已经在运行，避免两个进程同时写 `config.json` / `accounts.json`。

### 界面和手感

- **小屏不挤**：无边框窗口可拖四边四角缩放，页面放在滚动容器里，窗口变矮就出滚轮；内容卡片按宽度自动 4 → 3 → 2 列重排。
- **侧栏分组**：按「启动 / 下载 / 内容 / 联机 / 工具 / 设置」分组，点标签只看当前板块；关掉的功能模块会整组隐藏。美化版侧栏默认只显示图标，悬停才浮出名称。
- **11 套主题**：深色有森林绿、海蓝、暮紫、赤红、琥珀、青碧、樱花粉、极夜蓝；浅色有晨光、米白、薄荷浅。可以取色器自定义强调色，也可以导入 / 导出主题 JSON。
- **背景和壁纸**：可以指定任意图片作为启动器背景，按窗口比例等比铺满并居中裁切，不拉伸变形；美化版还支持 MP4 / WebM 视频与 GIF / WebP 动图循环静音播放，窗口切到后台自动暂停。
- **毛玻璃能调**：美化版可以调毛玻璃强度、背景亮度、卡片圆角、按钮尺寸和字体颜色，也能一键关掉毛玻璃与动画；低配机器不会被迫吃满特效。
- **字体颜色**：设置 → 外观可以单独调正文颜色，或恢复「跟随主题」，弱化文字和选色会一起刷新。
- **启动动画**：经典版的草方块进度不是装饰，填格用的是真实下载进度；下方阶段文字和百分比同步，结束或失败时淡出。
- **空状态引导**：没有版本、没有搜索结果、没有下载任务时，都会告诉你下一步能做什么，并给出直达按钮。
- **最近使用 + 相关功能 + Ctrl+K**：美化版主页记住最近 5 个功能；功能页底部有「相关功能」推荐；`Ctrl+K` 打开命令面板，输入关键词直接跳。
- **拖拽排序**：版本列表按住就能拖，松手写回配置；搜索过滤时暂停拖动，避免顺序错乱。
- **全局拖拽导入**：Mod、整个 `mods` 文件夹、整合包、资源包、光影包、世界 zip 拖进窗口就行，启动器会问装到哪个实例。
- **UI 材质包一键替换**：为选中版本生成半透明界面材质包，按版本自动适配，可以只生成、导入指定版本、导入全部版本、导出或启用。
- **任务胶囊 / 悬浮球**：有任务时窗口右下角会出现入口，点一下回下载中心，不打断你正在看的页面。
- **关闭确认**：经典版还有下载任务时会问「关闭（中断下载）」还是「手滑了」；美化版点关闭先落盘再快速退出，开了「关闭时最小化」就收起来。
- **托盘**：经典版可以关到系统托盘，点托盘图标恢复；美化版对应的是关闭时最小化。

### 数据、存档和皮肤

- **远古存档转换【少见】**：支持 Classic 2009（可识别的旧二进制）、Indev、Alpha、McRegion → Anvil → 目标版本，解析方块 ID 并重映射，多线程执行，原存档只读、结果另存到新目录。转换器会先统一输出 1.12.2 的 Anvil 中间格式，再写入目标版本的 DataVersion / Version 标记；1.13 之后的扁平化由游戏本体首次打开时完成。这样不用在启动器里重写整套 DataFixerUpper，也能把老存档搬进新版本。启动器里基本见不到这个功能，但专门的存档转换工具（如 Chunker、Universal Minecraft Tool）能做类似的事，所以标「少见」，不写「独家」。
- **老存档也能被找到**：自动发现旧命名格式的存档与历史备份，包括 `server_level.dat`、`*.mine`、Classic 压缩包内单文件 `level.dat`；可以转换后直接导入指定版本，不再因为命名差异扫不到。
- **转换不覆盖原件**：源文件夹、源 zip、Classic 单文件都只读；输出目录已存在同名世界时会自动加后缀，不会把原来的世界盖掉。降级只改版本标记，方块数据可能不兼容，界面会明确提示。
- **存档元数据工具**：改世界名、模式、难度、作弊、天气、时间、出生点与常用规则；写入前备份 `level.dat`，最多保留 5 份。
- **启动前自动备份**：默认开启，每个存档单独打包；同一世界 1 分钟内不重复备份，最多保留 20 份；备份失败不会阻止启动。
- **皮肤包全版本适配【少见】**：1.19.4 之后原版有 9 套默认皮肤，并按玩家 UUID 分配；很多皮肤包只覆盖 steve / alex，进游戏还是默认皮肤。MikanCL 会把 9 套默认皮肤名在 `player/wide` 与 `player/slim` 两个目录都写成同一张皮肤，并按 `pack_format` / `min_format` / `max_format` 适配版本；换皮肤或升级版本后都会自动重写，不会「装过一次就不再管」。这个做法在启动器里不常见，但别家也可能有自己的处理方式，所以标「少见」，不写「独家」。
- **皮肤头像**：从 64×64 皮肤裁出头部和帽子层，主页、侧栏、账号页统一使用；没有本地皮肤时异步拉取，失败回退像素头像。
- **NBT 编辑器**：13 种标签、gzip 自动识别、类型保留、树形编辑、根节点保护、未保存提醒、首次保存 `.bak`。
- **世界种子**：经典版是 3D 体素预览，能转、能缩放、能平移、能自动旋转；美化版生成高度图。两边都调用本机 Java 跑与游戏相同的噪声算法，不是随便画的山。
- **截图和崩溃**：截图本地看、批量打包、删除；崩溃日志汇总、摘要复制、目录跳转。

### 扩展和生态

- **Python 插件【少见】**：经典版 `data/plugins/` 下放一个 `.py` 文件就能新增侧边栏页面，`setup(api)` 里可以用版本、实例、内容搜索、下载、安装、后台线程等 API；单个插件出错只记日志，不影响启动器。启动器插件系统不常见，但别家也有扩展机制，所以标「少见」，不写独家。
- **Web 扩展**：美化版「设置 → 扩展」支持导入 `.zip` / `.mikan-ext`，启用 / 停用 / 删除 / 打开目录 / 刷新；扩展页面跑在沙箱 iframe 里，通过 `postMessage` 调启动器桥接接口。经典版的 Python 插件也会一起列出来。
- **内置 Wiki**：中 / 英 / 俄 / 法 / 日五套教程，首次运行自动写入，可以自己改、自己加。
- **五语言界面**：简体中文、English、Русский、Français、日本語，设置里可以切换（经典版重启后生效，美化版保存后生效）；界面里只显示语言名称，不带 `cn` 之类后缀。
- **单文件免安装**：一个 `MikanCL.exe`，配置和缓存写在同目录 `data/`，换机直接拷走；首次启动会先解压运行时，比目录版慢几秒。
- **内置浏览器**：美化版用 Edge WebView2 内核，Electron 版用自带 Chromium，B 站视频直接播，登录态保留；经典版支持多标签，网页版是独立浏览器窗口。
- **联机地址探测**：陶瓦地址生成后自动试连并显示延迟，失败可复测。

## 使用上的实话

1. **先装 Java 再装游戏**：启动器能帮你找 Java，但不能凭空变出来。第一次用，先去 Java 中心装一个，后面会省很多事。

2. **内存别拉满**：建议不超过物理内存的 70%。低配机器 2–4 GB 就够；整合包大、光影重，再往上加。预检会在超过 70% 时提醒。

3. **整合包安装会比较久**：要下基础版本、加载器、几百个 Mod，还要解压 overrides。中途可以取消，已经下好的 `.part` 会保留，下次继续。

4. **Mod 不是越多越好**：重复 modid、前置缺失、版本范围不满足都会让游戏起不来。装完先看模组管理的标红项，再看 Mod 关系网。

5. **离线皮肤别人不一定看得到**：本地皮肤、皮肤包只影响你自己；要让服务端和其他玩家看到，需要服务端装 CustomSkinLoader 或使用支持皮肤的网络。皮肤包默认只写入，不会自动启用，需要时在资源包管理里勾上。

6. **5 个版本同时安装是经典版的能力**：超出的会排队；单个版本内部再按文件并发。美化版可以同时进行多个任务，但没有 5 个安装槽位的队列提示。

7. **Forbric 只支持 26.2**：它是实验性加载器，版本对不上会直接拒绝安装，不会硬装。

8. **CurseForge 的 API Key 可能会变**：启动器内置了默认 Key，也允许在设置里替换；如果突然搜不到内容，先换 Key 或换网络试试。

9. **国内下载慢先换源**：设置 → 下载里可以选 Mojang 官方、BMCLAPI 镜像或自定义源，也可以加线程、走代理；不是所有文件都能从镜像拿到，失败会自动回源。

10. **单实例保护**：同时开两个 MikanCL 会提示已经在运行，这是为了避免两个进程同时写配置和账号文件。

11. **杀毒软件可能误报**：PyInstaller onefile 首次启动会解压运行时，行为像「自解压」，个别杀软会拦。加信任即可，启动器不会往系统目录写东西。

12. **基岩版不是 Java 版**：它需要微软账号拥有游戏或 Game Pass，安装走 Appx，和 Java 版的 Mod、光影、整合包都不通用；`0x803F8001` 先查账号和商店区域。

13. **依赖补全不会偷偷装东西**：扫描是只读的，确认后才会下载；任务全部进下载中心，可以取消。

14. **用户协议 v1.9 有 15 项**：包括非官方声明、账号、下载、数据与运行风险、隐私、免责、协议变更、世界种子、界面效果、第三方模块等；设置 → 关于可以随时重看。

15. **美化版依赖 WebView2**：Windows 10 / 11 通常自带；缺失时启动器会引导下载，也可以把固定版本运行时放到安装目录的 `webview2/` 里。

16. **onefile 首次启动会慢几秒**：它要先解压运行时；之后就快了。介意的话可以用源码运行，或用 PyInstaller 自己打一个 onedir 包。

17. **存档转换不是万能的**：它能把旧格式整理成 Anvil，并写入目标版本标记，但 1.13 之后的方块扁平化由游戏完成；极老的、无法识别的二进制会明确报错，不会硬转。跨大版本前请整份备份世界目录。

18. **配置和存档都在本机**：启动器不上传你的账号、存档或截图；换机时记得把 `data/` 一起带走，尤其是 `data/backups/`。

| 现象 | 先做什么 |
| :--- | :--- |
| 点启动没反应，或一直停在启动中 | 等看门狗提示；看 `data/logs/` 和崩溃报告；确认 Java 能被启动器识别 |
| 提示 Java 版本不匹配 | 去 Java 中心装对应主版本；急的话可以在预检弹窗里确认强启，但不建议长期这么用 |
| 游戏刚开就崩 | 看崩溃报告摘要；检查 Mod 冲突、前置缺失、内存是否够；用「恢复到上次能启动的配置」退回 |
| 整合包装到一半失败 | 看下载任务里的错误详情和 `missing_mods.txt`；重试失败项，或换下载源 |
| 皮肤进游戏不显示 | 确认皮肤包已在资源包里启用；服务端需要 CustomSkinLoader；1.19.4+ 还有 9 套默认皮肤，换皮肤后要重新确认皮肤包 |
| 基岩版安装失败 | 确认系统允许旁加载；看 PowerShell 输出；缺 VCLibs 时让启动器补依赖后重试 |
| 内置浏览器视频不能播 | 系统可能缺 WebView2，按提示安装；或先用系统浏览器打开 |
| 下载很慢 | 换 BMCLAPI / 自定义源，加线程，检查代理；大文件本来就会慢 |
| 界面卡顿 | 美化版关掉毛玻璃和动画，降低背景亮度；老机器直接用经典版 |
| 配置改坏了 | 设置 → 高级 → 恢复到上次能启动的配置；或从 `data/backups/` 找回 |
| 存档打不开 | 先用存档编辑看版本标记；同格式跨小版本用「版本」转换；旧格式用工具箱的完整转换器；`.bak` 和备份目录都能救命 |
| 启动器打不开 | 确认系统是 Windows 10 / 11 x64；看 `data/logs/install_error.log`；杀软拦截就加信任 |

## 给想动手的人

### 源码运行

```bash
python -m pip install -r requirements.txt
python run.py
```

Python 3.10+，Windows 10 / 11 x64。源码运行不需要 WebView2 也能用经典版；美化版仍然需要 WebView2。

### 打包

```bash
python build_exe.py
```

产物是 `dist/MikanCL.exe`，PyInstaller onefile，前端资源、翻译、图标、`mc_launcher/data` 都会打进去。首次启动会先解压运行时，所以比目录版慢几秒。

为什么不用 Nuitka：当前 Nuitka 尚未适配 Python 3.15，在 Python 3.15 环境下无法完成编译；PyInstaller 已支持 3.15，因此 v5.2.0 改用 PyInstaller，功能与运行行为不受影响。

### 数据文件

| :--- | :--- |

### 加下载源、加载器或任务类型

- **下载源**：在设置 → 下载里新增，或者改 `config.sources`；每个源有 `id` / `name` / `manifest_url` / `download_base` / `enabled`，失败会自动回源。
- **加载器**：在 `mc_launcher/modloader.py` 或 `installer.py` 里加元数据与安装函数，前端下拉会自动读列表；版本列表来自平台 API，不需要写死。
- **任务类型**：下载、安装、整合包、Java、存档转换都走同一套任务外壳；新增类型时提供 `stage`、`progress`、`cancel` 即可复用下载中心和通知。

### 插件最小例子

```python
# data/plugins/hello.py
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget

PLUGIN_NAME = "你好插件"


def setup(api):
    page = QWidget()
    layout = QVBoxLayout(page)
    layout.addWidget(QLabel("你好，" + api.app_name))
    api.add_page("你好", page)
    api.log("你好插件已加载")
```

插件 API 还包括导航、实例 / 版本列表、Java 与账号信息、内容搜索、下载、安装、后台线程等；单个插件异常只写日志，不会影响启动器。

### 主题 JSON

把主题文件放到 `data/themes/`，或在设置 → 外观里导入。主题就是一组颜色键值，导入后会出现在主题列表里；也可以用「导出当前主题」拿一份模板改。
